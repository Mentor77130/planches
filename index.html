    Google Drive

    Connectez-vous avec votre compte Google : la liste de vos fichiers Drive s'affiche, choisissez une BD et elle s'ouvre ici.

    La BD est téléchargée sur cet appareil, puis gardée pour la reprendre en un clic.

    Autre façon : le sélecteur de fichiers

    Avec l'app Google Drive (sur téléphone) ou Google Drive pour ordinateur, votre Drive apparaît aussi dans le sélecteur de fichiers de l'appareil.

    Avec l'app Google Drive pour ordinateur, connectée à votre compte Gmail, votre Drive apparaît dans le sélecteur de fichiers comme un disque.

    Sans l'app : téléchargez la BD depuis drive.google.com, puis glissez-la sur cette page.

    Avec l'app Google Drive, votre Drive s'ouvre dans le sélecteur de fichiers de l'iPhone, même pour les très grosses BD.

    Votre Drive s'ouvre dans le sélecteur de fichiers du téléphone, même pour les très grosses BD.

    1. Touchez « Choisir le fichier ».
    2. En bas, touchez « Parcourir », puis « Drive ».
    3. Touchez la BD : elle s'ouvre aussitôt.
    « Drive » n'apparaît pas ?

    Installez l'app Google Drive depuis l'App Store et connectez-vous avec votre compte Gmail. Ensuite, dans « Parcourir », touchez « ••• » en haut, puis « Modifier », et activez Drive.

    1. Si le téléphone le demande, choisissez « Fichiers ».
    2. Ouvrez le menu ☰, puis touchez « Drive ».
    3. Touchez la BD : elle s'ouvre aussitôt.

    iCloud Drive

    Apple ne permet à aucun site web d'afficher directement votre iCloud Drive. Vos BD qui s'y trouvent s'ouvrent par le sélecteur de fichiers de l'iPhone :

    1. Touchez « Choisir le fichier ».
    2. Touchez « Parcourir », puis « iCloud Drive ».

    iCloud Drive n'existe pas sur Android. Téléchargez la BD depuis icloud.com, puis ouvrez-la ici avec « Choisir un fichier », dans « Téléchargements ».

    Aller sur icloud.com

    Apple ne permet à aucun site web d'afficher directement votre iCloud Drive. Sur Mac, il apparaît dans le sélecteur de fichiers ; sur Windows, une fois l'app iCloud installée.
