Planches

Confidentialité

Vos BD restent sur votre appareil. Planches n'a ni compte, ni serveur qui reçoit vos fichiers, ni publicité, ni mesure d'audience.

Les BD que vous ouvrez

Un fichier ouvert depuis votre appareil est lu par votre navigateur lui-même : il n'est envoyé nulle part.

Pour que vous puissiez reprendre une lecture en un clic, le navigateur garde sur cet appareil, et seulement sur celui-ci, une copie de la BD, l'image de sa couverture et la page où vous vous êtes arrêté. Quand la place manque, les copies les plus anciennes sont effacées.

Pour tout effacer : touchez « Retirer » sous une BD de l'étagère « Reprendre la lecture », ou effacez les données du site dans les réglages de votre navigateur.

Google Drive

Si vous touchez « Ouvrir mon Google Drive » :

  • vous vous connectez dans une fenêtre de Google ; Planches ne voit jamais votre mot de passe ;
  • Planches demande une seule autorisation, « drive.file », limitée aux fichiers que vous choisissez vous-même dans le sélecteur de Google. Le reste de votre Drive lui reste inaccessible, et il se contente de lire les fichiers choisis : il n'en modifie ni n'en supprime aucun ;
  • la BD choisie est téléchargée directement depuis Google vers votre appareil, puis gardée comme expliqué plus haut ;
  • l'autorisation donnée par Google reste en mémoire le temps de votre visite : elle n'est pas enregistrée et n'est transmise qu'à Google.

Vous pouvez retirer cet accès à tout moment depuis votre compte Google.

L'utilisation des informations reçues des API Google respecte le Règlement sur les données utilisateur dans les services d'API Google, y compris les exigences d'utilisation limitée.

Services utilisés par le site

Le site est hébergé par GitHub Pages et sa police d'écriture vient de Google Fonts. Comme pour toute page web, ces services reçoivent l'adresse IP de votre appareil quand ils envoient leurs fichiers ; Planches n'y ajoute aucune information sur vous. Les outils de connexion de Google ne sont chargés que lorsque vous survolez ou touchez le cadre Google Drive.
